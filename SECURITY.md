# Package security

The [public security policy](https://github.com/Devrajsinh-Jhala/consequa-x-community/security/policy)
and [private vulnerability reporting form](https://github.com/Devrajsinh-Jhala/consequa-x-community/security/advisories/new)
are available without access to the private research repository. Reporting uses
a GitHub account. Do not post production captures, customer data or credentials.
Use a minimal synthetic reproduction with package, Python and OS versions.

The latest stable release is the primary maintenance target; no response SLA or
long-term support duration is promised. Consult public release notes for fixes
and compatibility changes. See docs/offline-reports.md for the default omission
boundary and the potentially sensitive --include-details mode.
