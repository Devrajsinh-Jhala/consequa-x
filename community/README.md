# Consequa-X documentation and support

Consequa-X is a Python framework for inspecting consequential agent actions.
It separates a tool response, the agent's reported assessment, independently
captured state, and effect origin. A timeout can coexist with a completed effect.

- [Website and documentation](https://consequa-x.brawny-deer-5658.chatgpt.site)
- [Python package](https://pypi.org/project/consequa-x/)
- [Five-minute quickstart](QUICKSTART.md)
- [Report a reproducible bug](https://github.com/Devrajsinh-Jhala/consequa-x-community/issues/new/choose)
- [Security policy](SECURITY.md)
- [Release notes](CHANGELOG.md)

This public repository contains documentation, synthetic examples and issue
templates. The framework research/source repository is private. No retained
research datasets, credentials or model weights are published here. The Python
wheel and source distribution are public under MIT; the source distribution
includes the implementation, application examples, tests and documentation.

Version 1.1.0 is published on PyPI. Both distribution hashes and sizes were
verified on 17 October 2026. A visual report is a presentation of captured
evidence, not provider authentication, automatic causal proof or a production
payment integration.

For help, open a question or bug using the issue templates. Public issues need
a GitHub account. Use synthetic minimal traces and remove customer data; never
post credentials or private captures. Maintainer responses are best effort,
with no guaranteed response time. Security concerns use the private reporting
route in SECURITY.md, rather than a public issue.
