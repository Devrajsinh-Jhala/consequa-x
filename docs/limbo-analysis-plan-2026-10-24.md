# Frozen external comparison: analysis plan

This plan and its executable postprocessor are published before official model
generation. The excluded development data are visible; no official outcome
has been collected. The endpoint is a complete audited finite comparison,
including null or adverse findings, rather than a favorable score.

The schedule has 12 base instances (one per native template), 24 assigned
clean/fault conditions and 96 slots. Each arm has 24 planned slots. No arm,
case, error, unstarted slot or untriggered assigned fault is excluded after
collection. Native model generation is serial and one-shot, with no resume,
corrective generation or replacement.

Primary descriptive endpoints are the numbers of independently replayed true
native TS and native EOS grades over all 24 planned slots per arm. Available
false grades and unavailable grades are separately counted. A native LLM-error
return after ordinary native flush can have an audited physical grade; it is
included in the primary numerator if that unchanged grade is true. Normal
execution and error dispositions are reported separately. Missing native
grades remain unknown, never fabricated semantic zeros.

Report all native secondary fields: clean_success, exact_state, executed/live/
compensated duplicate counts, collateral, extraneous writes and total effects.
EOS is domain-qualified; status/upsert/refund counting and target-scope
limitations are explicit in methods. Do not substitute EOS for universal
exactly-once execution or full-world correctness.

Compare arms within the same assigned native world. Report all six pairwise
contrasts, including the primary integration comparison of native guard with
the actual ConseqaX receipt arm. For each endpoint retain both available
denominators, discordant observed pairs, pairs with unavailable grades and
all-planned numerator differences. Agreement is conformance of the shared
control law, not independent algorithmic novelty, statistical equivalence or
general safety. Different model-generated trajectories can still occur.

Describe variation by template, focal domain, family and assigned fault mode.
Never condition inclusion on post-execution fault triggering. Clean/fault
variants share base parameters but have mode-dependent native RNG seeds.
They are not identical random worlds or independent tasks. No population
confidence interval, significance test or random-task generalization is made.

Costs distinguish model invocations, generation dispatches, returned
completions, cap refusals, actual execute/verify/advance/flush boundaries,
explicit outer waits, virtual wait seconds, receipt count and receipt-bearing
episodes. Advances nested inside tools include ordinary service latency and
are not policy waits. Boundary attempts are not physical effects. Report
availability for work and token totals; do not interpret unquantified work as
zero. Cached input is a subset of input tokens and is not added again.
Wall time and sampled resources describe this shared CPU host, not isolated
SDK overhead.

Only a sealed, passed official independent audit bound to the published exact
protocol commit can enter the postprocessor. It reconstructs all 96 schedule
identities independently, validates raw row semantics and ignores convenience
summary counts. The three result figures and generated tables/narrative use
those audited rows alone. Synthetic fixtures are confined to test temporary
directories and are never paper evidence. Final paper compilation binds the
actual analysis, manuscript sources and figure bytes; all pages require visual
inspection before delivery.
