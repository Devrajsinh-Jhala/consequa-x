## Fixed scope and endpoint

Finish a generic IEEE research manuscript whose empirical claims follow from
completed, audited experiments. Positive, null and adverse findings are valid;
framework superiority is not a completion requirement and must not be invented.
Venue acceptance cannot be promised. Venue selection/submission is separate
from completing this evidence-backed manuscript.

The primary external experiment now uses the author-pinned LIMBO environment,
native task construction/faults and native grader. Its faults directly exercise
ambiguous commits, unlike the synchronous airline pilot. Retain the airline
development failure as feasibility evidence; do not relabel it or silently
replace an official score (none was collected).

The prospective schedule covers all 12 external templates across six domains,
one metadata-hash-selected base instance each, in a clean condition and one
compatible fault condition. Four arms give 24 task/fault cases and 96 planned
slots on 12 base instances, not 96 independent tasks. Native mode-dependent
world seeds are retained and disclosed; clean/fault comparisons are not falsely
described as identical random worlds. Compare arms within each native world.

Arms are unchanged vanilla, unchanged SDK retry, unchanged strong native guard,
and a real ConseqaX 2.1.1 receipt integration of that same strong guard. Parity
supports integration/conformance and equal recovery law, not a novel algorithm.
Native task success, domain-qualified exactly-once metrics, harmful effects,
extraneous writes and actual execute/verify/wait/model costs remain separate.

## Required completion gates

1. Validate actual policy/receipt integration and unchanged strong-guard parity
   on invented native worlds; keep gold and evaluator state outside the package.
2. Validate local structured tool roundtrips, full-history/token/context checks,
   one-send accounting and failure retention using the actual local model.
   A development mutation and actual package receipt must be exercised before
   freezing the measured study; task reward one is not a readiness requirement.
3. Commit and publish source/runtime/native/wheel identities, metadata-only
   selection, all planned slots, budgets and analysis before official generation.
4. Execute that matrix once under shared limits; never replace failed or
   unstarted slots. No automatic retry/resume changes the denominator.
5. Independently replay saved actual calls, virtual waits and pending-effect
   settlement, reconstruct final world/ledger, and reproduce native grades.
   Missing grades or usage remain unavailable. Reject unauditable artifacts.
6. Analyze every planned slot, matched per-world contrasts, template/domain/fault
   coverage, failures and resource availability. Avoid task-population inference
   from repeated arms or generated variants. Report strong-reference parity and
   receipt semantics exactly, including native metric limitations.
7. Replace prospective manuscript claims with actual audited findings, update
   related-work/contribution/limitations consistently, and produce legible
   results figures and tables bound to the audit. Finish all-page PDF QA and
   publish a reproducible, licensed artifact with hashes and exact sources.

Do not call the paper complete before these gates close. If runtime or data
integrity prevents a gate, preserve the evidence and repair the execution path
under a separately declared prospective condition. Cosmetic additions and more
internal test counts are not substitutes for a completed external comparison.
