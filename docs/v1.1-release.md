# Version 1.1 release checklist

Version 1.1 is a bounded adoption release. It adds offline HTML evidence reports
and public onboarding without changing portable schema 0.1 or the established
version-1 core. Release files are built from a frozen source revision and kept
immutable after validation. Historical 1.0 distributions and research collections
retain their original bytes, source revisions and manifests.

## Required gates

1. The complete source suite, report adversarial tests, publisher guard tests and
   source lint pass without a model, API key or GitHub Actions.
2. Wheel and source archives pass strict metadata and exact source-file inventory
   checks. Package version, MIT license, typing marker, bundled schema, zero
   required runtime dependencies and public documentation/support URLs agree.
   Private retained data, paper PDFs, website assets, credentials and virtual
   machine files are excluded from Python distributions.
3. Fresh installed-artifact checks run outside the checkout with isolated imports
   on Windows Python 3.11 and 3.12 and one actual Linux environment. The checker
   verifies every installed wheel payload, trace round-trips, explicit custom
   adapters, unknown/other-actor semantics, strict input refusals, HTML disclosure
   and source/existing-output preservation. A pure-Python wheel alone never
   establishes a platform result. macOS is not claimed without a real run.
4. Browser review covers normal, unknown, conflicting-witness, hostile-detail and
   long-graph reports, with desktop, mobile and print presentation considered.
   Report data stays inert and offline; full node/link tables retain data even
   when the visual overview is bounded.
5. Public landing, quickstart, example downloads, release notes, support and
   private vulnerability reporting are reachable without private-repository
   access. The landing explorer is explicitly synthetic. A downloaded quickstart
   runs with the reviewed installation and preserves unknown evidence.

The stable publisher requires four additional true gates from 1.1 onward:
`report_security`, `report_browser_qa`, `linux_wheel_install` and
`public_docs_support`. Legacy 1.0 receipts remain valid under their original
gate set. Receipts identify actual test counts, source and artifact hashes,
interpreter/OS versions, browser checks and publication state; they do not infer
new scientific results from product usability improvements.

## Artifact records and public destinations

The retained [1.1 release directory](../output/release-1.1.0-2026-10-17/) contains
the reviewed wheel/source archive and build, inventory, installation, browser,
publication and exact-file manifest records. Check `checks.json` for the final
source revision and gate results; a changelog entry alone is not a publication
receipt. Public distributions are available through
[PyPI](https://pypi.org/project/consequa-x/).

- [Landing and documentation](https://consequa-x.brawny-deer-5658.chatgpt.site)
- [Public community support](https://github.com/Devrajsinh-Jhala/consequa-x-community)
- [Private vulnerability reporting](https://github.com/Devrajsinh-Jhala/consequa-x-community/security/advisories/new)

The research/source repository remains private and GitHub Actions remains
disabled. Public site/support source is a deliberately sanitized subset;
private empirical records and the IEEE paper are not part of that publication.
