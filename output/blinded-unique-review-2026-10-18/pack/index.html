Use two independent reviewers before discussing labels. Preserve both original annotation files and later adjudication separately. Blank means unreviewed; unknown means reviewed evidence is insufficient. Repeated evidence is not an independent task. This file works offline.

Labels at a glance

State: satisfied / violated / unknown. Match payment, amount, currency, exact count, deadline and persistence horizon.

Action-linked target: satisfied / not_satisfied / unknown. Check sufficient qualifying effects linked to this action and actor. State satisfaction alone does not establish action linkage.

Origin: confirmed / other_actor / unknown. Separate observed provenance from target correctness and causal responsibility.

A tool acknowledgement is not an independent effect witness. Missing, stale or incomplete readback cannot establish absence. Read the full rubric before labeling; equal opaque IDs are meaningful only within one card.
