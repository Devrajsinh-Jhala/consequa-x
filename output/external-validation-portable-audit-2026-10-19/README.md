# Portable external-validation artifact audit

Portable integrity/accounting audit, not independent semantic or human validation.

The audit passed with no framework imports, model calls or native tool execution. See audit.json for closed-study counts, hashes and checking scope. Historical protocols were not rewritten. No reviewer private mapping was read or emitted.

The auditor checks the original protocol seals, bound local/upstream/dependency file bytes, the public judge inputs and exact raw requests/responses, its ordered hash-chained journal, completed receipts, and recomputed reported fractions/strata. For Tau it checks every planned episode and start, capture labels, withheld/origin accounting, native call execution counts, and summary counts. Explicit path relocations are recorded in audit.json; changed working source is accepted only when its original bytes match the pinned Git object. Missing bindings fail.

This is artifact integrity and accounting, not source authentication, an independent semantic oracle, human annotation, or an autonomous-agent benchmark result. Optional figure and review-pack checks establish their declared hashes and inventory, not the validity of their scientific interpretation.
