# Stronger comparisons and benchmark transfer

This is a prospective plan for new collection, written after the closed
504-slot factual study. Each component must freeze its own exact source,
parameters, input schedule, dependencies and external revision before its
first measured execution. It is an internal timestamped protocol, not an
external preregistration. Earlier evidence and package runtime remain unchanged.
No GitHub Actions, paid inference, real payment or production service write is
permitted by this plan.

## Separate questions

1. **Official CAR execution.** Does a tested bridge to the unmodified pinned
   upstream implementation give the same point effects as Consequa-X on a
   shared declared refund decision game and shared replay draws? Report native
   interval behavior, complete-result availability and actual cost, rather than
   treating agreement as a new attribution method or superiority result.
2. **Same-evidence model judge.** How does one frozen local model interpret the
   same public contract/readback/provenance used by deterministic auditors?
   Distinguish wrong definite claims, unsupported but hindsight-correct guesses,
   abstentions and invalid outputs. This is not human annotation or causal
   attribution.
3. **Maintained benchmark state transfer.** Can application verifiers consume
   captured state from the maintained tau-bench retail and airline environments
   through the public framework API, including controlled missing/incorrect
   writes and false acknowledgements? Native task DB checks and action-specific
   postcondition checks remain separate. Reference-action replay is integration
   validation, not an autonomous-agent pass@k or leaderboard score.

The original tau-bench repository now labels its tasks outdated. Benchmark
collection must use the reviewed maintained `sierra-research/tau2-bench`
revision `96a3ef92329baf908ffe9dfe188cea34e8701d2a` (tau3 branding, package
1.0.1), preserving task, data, tool and evaluator hashes. The CAR source is
`jaineet17/causal-agent-replay` revision
`db90fa28b97164c35e7c524e4597b8cbdb3035af` (package 0.2.0). Neither upstream
implementation is included in the public Consequa-X distribution.

## Binding design rules

The component documents specify exact schedules and sample counts:

- `docs/upstream-car-comparison.md`
- `docs/matched-trace-judge.md`
- `docs/tau-benchmark-validation.md`

Before collection, review the complete adapter code, pass meaningful offline
tests, create a source commit, and write exclusive protocol/input manifests.
Record inspected dependency versions and the exact external source bytes.
Refuse changed inputs or sources, rather than silently continuing under a new
protocol. Preserve all failed or partial executions; never replace a started
sample or tune the model/prompt after seeing measured outputs.

The judge subset is fixed by **repetition 0** in the earlier frozen schedule:
84 planned inputs across the original three generators, two profiles and
fourteen case/wording cells. It was selected after factual collection but before
any judge output, using a rule independent of outcome. Report its 84-slot
denominator separately from the original 503-completed/one-failed pool. This is
a balanced conditional comparison, not a new held-out task sample. The judge
is the installed local Qwen3 4B checkpoint; record its full digest, prompt,
schema, seeds, generation settings, attempted calls, bytes and response identity.
Use one call per available input and no corrective retry. Never transmit hidden
ledger data, case/fault/generator labels, prior verdicts, explanations or paths
to the judge. Consistent opaque aliases must preserve equality and origin joins.

For CAR, use the same decision units, continuation policy, outcome contract,
readback and on-reach semantics in both arms. Native rollout budget and actual
fresh policy-call budget are different quantities; count both. Do not silently
relabel unknown as a good outcome. Preserve native partial diagnostics but
require the predeclared complete-method gate for the primary comparison.
Bootstrap/normal and conservative intervals remain named methods. A small
scripted bridge study supports numerical/semantic compatibility; it does not
establish live-model attribution accuracy or precise population calibration.

For benchmark transfer, preserve the upstream tools and relevant evaluator
bodies. Any namespace-only bootstrap used to avoid unused model/voice imports
must be disclosed and hash-bound. Auditor inputs contain intended operation
payload and captured readback, not hidden reference-action lists or task gold.
Application predicates need independent payload-derived controls. Do not score
action-postcondition errors against a whole-task label when the estimands differ.
Missing natural-language judgment components must never become a full native
task reward. Native reference replay can still fail; retain such failures and
their original denominators rather than selecting only successful tasks.

## Analysis and stopping

Retain full planned, started, completed, failed, refused and unstarted counts.
Every rate keeps its numerator and denominator, with null for zero denominators.
Keep each target, method, task/domain, model-generator and fault/control stratum
visible. Correct-definite yield over all planned slots is an operational
measurement, separate from conditional error among available claims. Source
qualification is separate from hindsight correctness.

Fixed mechanisms and repeated seeds are not independent task populations.
The judge has fourteen original case cells; reference replays are not stochastic
agent samples. No pooled independent-task significance, causal identification,
model ranking, broad transfer, independent human validation or conference
acceptance follows automatically. A native autonomous-agent benchmark run with
the original user simulator and all grading components remains a distinct
experiment. Controlled causal-agent comparisons beyond the scripted bridge also
remain distinct from factual judgment.

Collection stops at each frozen component's call/time limits or infrastructure
failure. An analysis may proceed on a closed, incomplete collection only with
all dispositions explicit. Final results require artifact and fraction audits,
then a new manuscript/PDF revision with visual checking. Any later descriptive
addition must be labeled with its timing and must not replace a frozen primary
metric.
