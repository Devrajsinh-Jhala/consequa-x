# Matched recovery checks and descriptive strata

Every planned case/seed pair is retained. Final state/linkage claims, the endpoint vector, controller action kinds/times/dispatch identities, and full-ledger truth are compared. Diagnostic decision wording and package-specific report metadata are not parity targets. Mismatches are reported, not rejected. A shared application state machine means reference agreement is implementation conformance, not superiority or external replication.

Capability/domain strata are descriptive views of all scheduled cells, not new independent task samples. Failed execution contributes zero only to the operational primary; unavailable semantic/resource values retain their missing denominator. Capabilities use consistent public declarations; a wholly unavailable declaration remains an unavailable stratum. These views do not add population inference or independent human evidence-support labels.
