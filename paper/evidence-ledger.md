## Reproducing the analytic reference check

From the repository root, use Python's standard library only:

```console
python paper/verify_analytic_references.py --output paper/analytic-reference-check-fresh.json
```

The output must be a new file. The retained receipt binds its script SHA-256 and
lists every case: the exact grid `0, 1/5, 1/2, 4/5, 1` for both `p` and `q`,
both idempotency settings, and action/consequence targets. This yields 100
control cases, 800 coalition values, 3,200 weighted Boolean components and 600
permutation orders. Every comparison uses exact fractions. The script imports
no framework code, reads no retained study files, makes no model/network calls
and does not execute the simulator. It independently checks the mathematical
four-component law and six-order allocation against the printed closed forms;
it is not an independent execution audit or a sampling-calibration experiment.
Assumptions and limits are included in the receipt. Repeated targets and control
settings are not independent empirical replications.

The stronger follow-ups do not share one denominator or validation status.
The judge subset has 84 selected inputs and seventeen evidence patterns;
the model-free benchmark uses 164 source tasks and 656 deterministic control
cells, with 900 action-level captures. Their audits do not supply independent
human labels, and benchmark DB equality is not the action-field predicate's
ground truth. The final native CAR audit checks all 1,024 pairs: 640 eligible
with exact point parity and 384 unavailable for both engines. All factual/call
totals agree, and no non-budget discrepancy was found. The separately disclosed
64-group collector limitation restricts native refused-attempt interpretation;
it does not change eligible estimates or fresh-call accounting.
The software's 1.1.1 metadata release, additive 1.2.0 and breaking 2.0.0 leave
every historical source/version pin above unchanged, as does current 2.1.1. The
separate sealed 2.0 migration study reports 503/503 canonical agreement, including
unknown evidence, over 503 retained traces / 504 original slots and 275 exact
diagnosis-code changes. It supplies post-hoc compatibility evidence only; the
independent artifact audit completed 71,383 checks with zero errors, and current
2.1.1 feature validation is unmeasured.
